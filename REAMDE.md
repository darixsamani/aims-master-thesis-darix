# Summary

This thesis at AIMS Rwanda investigate thirteen deep learning architectures for mutli-cateory defect classication using the data that has been collected in three regions in camerooon.

in the notebook we begin by make exploratory data anaalysis for the dataset and more plot the sample image by category.

and then we start from simple architceture to modern deep learning computer vision model by apply transfer leanring technique to train theses model on our own african plum dataset and evaluation the model based on the following metric, Accuracy, F1 (weighted), F1 (macro)c etc...
